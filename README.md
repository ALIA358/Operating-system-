# Operating Systems (CS3104)

This repository contains lab implementations, shell scripts, simulations, and project for the **Operating Systems** course.

## Topics Covered
- **Linux Process Management:** Observing and managing processes using `ps`, `top`, `htop`, and process states (`R`, `S`, `D`, `Z`).
- **Process Synchronization:** Critical-section problem, Peterson's solution, mutex locks, semaphores (binary & counting), and monitors.
- **CPU Scheduling:** FCFS, SJF, Priority, Round Robin (RR), and Multilevel Feedback Queue (MLFQ).
- **Deadlocks:** Deadlock characterization, Banker's algorithm (avoidance), prevention, and detection & recovery.
- **Memory Management:** Paging and page replacement algorithms (FIFO, Optimal, LRU, Clock / Second-Chance).

## Tech Stack & Environment
- **Languages:** C / C++, Bash Shell Scripting
- **Tools:** GCC, Linux (Ubuntu), Visual Studio Code
